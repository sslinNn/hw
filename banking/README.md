* zookeeper и kafka: <br>
Необходимы для настройки брокера сообщений Kafka.

* redis:<br>
Используется для кэширования курсов валют.

* postgres:<br>
База данных для хранения информации о транзакциях.

* transaction_manager_service:<br>
Сервис для управления транзакциями.
Подключен к Kafka и открыт на порту 5000.

* transaction_service:<br>
Сервис, который обрабатывает события из Kafka и записывает данные в базу данных PostgreSQL.

* valute_converter_service:<br>
Сервис для конвертации валют, использующий Redis для хранения курсов валют и Kafka для обработки событий.

* networks:<br>
Определена сеть banking_net, которая позволяет всем сервисам взаимодействовать друг с другом.
